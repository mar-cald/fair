Glossario minimo

Termine Significato
DOI Identificatore persistente che punta a un oggetto digitale. Continua a funzionare anche se l’indirizzo cambia, perché è un sistema di reindirizzamento gestito.
Metadati Dati sui dati: titolo, autori, data, descrizione, licenza. Sono ciò che rende un dataset trovabile.
Data dictionary / codebook Documento che descrive ogni variabile: significato, tipo, unità, codifica, valori mancanti.
ORCID Identificatore univoco per le persone che fanno ricerca. Risolve il problema degli omonimi e dei cambi di cognome.
Embargo Periodo durante il quale i metadati sono pubblici ma i file non sono scaricabili. Si usa per attendere la pubblicazione dell’articolo.
Accesso ristretto I file si ottengono solo dopo una richiesta approvata, di solito con un accordo scritto (Data Use Agreement).
Pseudonimizzazione Sostituire gli identificativi con codici, mantenendo altrove la chiave di collegamento. Il dato resta personale.
Anonimizzazione Rendere impossibile risalire alla persona, in modo irreversibile.
Versionamento Conservare la storia delle modifiche, in modo che ogni versione resti citabile. Lo fanno git per il codice e i repository per i depositi.
Riproducibilità Ottenere gli stessi risultati dagli stessi dati con lo stesso codice.
