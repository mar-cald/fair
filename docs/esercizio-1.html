Regole generali

  • Niente spazi, accenti o caratteri speciali nei nomi di file e di variabile: rompono gli script, i link e i trasferimenti fra sistemi operativi.
  • Numeri con lo zero davanti (01_, 02_): altrimenti 10_ viene prima di 2_.
  • Il nome dice cosa contiene.
  • Se serve una versione, usate _v1, _v2, o meglio ancora usate git.
  • Usare separatori e maiuscole in modo sistematico e significativo, non a caso: questo_e_snake_case, questoInveceECamelCase. Scegliete una convenzione e tenetela.

Che cos’è un README

È il file che risponde alle domande che una persona si fa prima di poter usare qualunque altra cosa ci sia nella cartella. Va scritto pensando a un destinatario preciso: qualcuno competente del vostro settore, che però non sa niente di questo studio e non può scrivervi.

Sta nella root del progetto/cartella, si chiama README.md ed è in Markdown o .txt

Sezione Risponde a
Titolo e autori (con ORCID) Di chi è questo lavoro, e a chi scrivo se qualcosa non torna
Di cosa si tratta Che studio è, che disegno, chi sono i partecipanti, quando sono stati raccolti i dati
Contenuto dei file Cosa c’è nella cartella, file per file, e qual è l’unità di osservazione
Come leggere i dati Cosa mi serve per accedere ai dati?
Come riprodurre In che ordine girano gli script, con che software, cosa producono
Licenza A quali condizioni si può riusare, e cosa vale per cosa
Come citare C’è una citazione per il progetto?/un DOI?
Materiali collegati DOI dell’articolo, della preregistrazione, del codice

Che cos’è un data dictionary

Il README descrive il progetto. Il data dictionary descrive ogni singola colonna dei vostri dati: una riga per variabile, in un file a parte (<nome_dataset>_dictionary.csv).

Colonna Cosa ci va Esempio
variable_name Il nome esatto della colonna, carattere per carattere rt
label Che cosa misura Tempo di reazione
type integer, numeric, string, categorical, date, boolean numeric
unit Unità di misura. Vuoto se non ne ha milliseconds
allowed_values Intervallo o elenco dei valori possibili 200-2000
coding Il significato di ogni codice, per le categoriali 1 = Psicologia; 2 = Economia
missing_values Come sono rappresentati, e se si sa perché mancano cella vuota
source Da dove viene il dato: strumento, questionario, calcolo PsychoPy
notes Decisioni prese, anomalie, avvertenze …
