Dove mettere dati, codice e materiali, a quali condizioni, e cosa allegarci perché qualcun altro possa usarli.

1. DATI

Dove: Zenodo (50 GB per record) · PsychArchives (1 GB per oggetto) · Research Data Unipd

Licenza: CC0, o CC BY 4.0 se volete l’obbligo attribuzione.

Con: README e data dictionary

2. MATERIALI

Dove: nello stesso deposito dei dati. Oppure su GitHub o GitLab (es. task sviluppati su PsychoPy/Pavlovia)

Licenza: CC BY 4.0

Mai: i test commerciali. Si citano, non si depositano

3. CODICE

Dove: GitHub per lavorare, una release archiviata su Zenodo per avere il DOI

Licenza: GPL-3.0 per il copyleft, MIT per la massima libertà

Con: un file CITATION.cff
