# Mindfulness e interferenza Stroop

Dati e codice dello studio sull'effetto di un breve training di mindfulness
sull'interferenza Stroop (Verdi & Neri, preprint 2025).

## Struttura

- `data/raw/psychopy/`: un file per partecipante, esportato da PsychoPy
- `data/participants.csv`: gruppo, età, sesso e punteggio MAAS
- `analysis/`: script di analisi
- `manuscript/`: il preprint
